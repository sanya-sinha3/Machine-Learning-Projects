# Machine Learning Projects

Machine learning projects built with Python and Scikit-learn, covering regression, classification and clustering.

## House Price Prediction
Predicts house prices using Linear, Ridge and Lasso Regression with cross-validation.
- Dataset: 2,918 records
- Result: R² = 0.346, Adjusted R² = 0.305

## Loan Approval Prediction System
Predicts whether a loan application is Approved or Rejected.
- Models: Logistic Regression, KNN, Naive Bayes
- Result: Naive Bayes selected as best model (79% precision)

## SmartCart Customer Segmentation
Groups customers using K-Means clustering based on purchasing behaviour, engagement and loyalty.
- Dataset: 2,236 customers, 19 features
- Optimal k = 4 (Elbow Method and Silhouette Score)

## Titanic Survival Prediction
Compares Logistic Regression, KNN, Naive Bayes, Decision Tree, Random Forest and Bagging.
- Decision Tree tuned with pre-pruning and post-pruning
- Result: Decision Tree, 84% accuracy

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Jupyter Notebook
